The `Probot` struct is the central object in probot-go. It owns the webhook event pipeline, manages GitHub App and installation-level authentication, exposes HTTP handlers you can mount in any `net/http` server, and provides the `RunAction` entry-point for running directly as a GitHub Action. All exported methods are safe for concurrent use.

## Import

```go
import probot "github.com/Pratyay360/probot-go"
```

---

## Constants

```go
const Version = "0.1.0"
```

The current version string of this Go port. Also accessible at runtime via `(*Probot).Version()`.

## Type Definitions

```go
// HandlerFunc is a webhook event handler. It receives a *Context and may
// return an error that will be routed to the registered error handler.
type HandlerFunc func(ctx *Context) error

// ApplicationFunc is a function loaded into a Probot instance via Load.
// It typically registers webhook handlers.
type ApplicationFunc func(app *Probot, opts ApplicationFunctionOptions) error

// ApplicationFunctionOptions are options forwarded to an ApplicationFunc.
type ApplicationFunctionOptions struct {
    Cwd string
}

// ErrorHandlerFunc handles errors raised inside webhook handlers.
type ErrorHandlerFunc func(ctx *Context, err error)
```

<ResponseField name="HandlerFunc" type="func(ctx *Context) error">
  The signature every event handler must satisfy. Return a non-nil error to
  propagate it to the registered `ErrorHandlerFunc`.
</ResponseField>

<ResponseField name="ApplicationFunc" type="func(app *Probot, opts ApplicationFunctionOptions) error">
  A plugin-style function accepted by `Load`. Typically registers handlers on
  `app` and reads `opts.Cwd` to locate config files relative to the caller.
</ResponseField>

<ResponseField name="ApplicationFunctionOptions" type="struct">
  <Expandable title="fields">
    <ResponseField name="Cwd" type="string">
      Working directory forwarded by `Load`. Currently set to `"."`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="ErrorHandlerFunc" type="func(ctx *Context, err error)">
  Called after all handlers for a delivery have run, with the joined error from
  any that returned non-nil. Register one with `OnError`.
</ResponseField>

## Constructor

### `New`

```go
func New(o Options, defaults ...func(*Options)) (*Probot, error)
```

Creates and initialises a `Probot` instance. Initialization is **synchronous** — the returned value is ready to use immediately. Register handlers with `On` / `OnAny` / `OnError` after `New`.

<ParamField path="o" type="Options" required>
  Primary configuration. `Defaults()` functional options are applied first;
  fields in `o` take precedence. See the [Options reference](/api/options) for
  every field.
</ParamField>

<ParamField path="defaults" type="...func(*Options)">
  Zero or more functional options produced by `Defaults(o Options)`. They fill
  zero-valued fields in `o` before validation. Useful for sharing a common base
  configuration across multiple instances.
</ParamField>

**Returns** `(*Probot, error)`. Errors are returned when `AppID` is supplied
without `PrivateKey` (or vice-versa), when `AppID` cannot be parsed as an
integer, or when the private key cannot be loaded into a JWT transport.

<Note>
  Passing neither `AppID`/`PrivateKey` nor `GithubToken` is valid — the
  resulting instance has no authenticated GitHub client and is intended for
  serving the setup wizard only.
</Note>

```go
opts, err := probot.OptionsFromEnv()
if err != nil {
    log.Fatal(err)
}

app, err := probot.New(opts)
if err != nil {
    log.Fatal(err)
}
```

## Lifecycle Methods

### `Ready`

```go
func (p *Probot) Ready() *Probot
```

Returns the `Probot` itself. Provided for API parity with the Node.js probot
library, where `app.ready()` is an async promise. In this Go port initialization
is synchronous, so `Ready` is a no-op that simply returns the receiver.

---

### `Done`

```go
func (p *Probot) Done() <-chan struct{}
```

Returns a channel that is closed once `Probot` has been fully initialized. The
channel is closed inside `New` before the function returns, so a read on
`<-app.Done()` completes immediately for any instance obtained from `New`.
Useful in select statements or for patterns that expect a ready-channel.

---

## Accessor Methods

### `Log`

```go
func (p *Probot) Log() zerolog.Logger
```

Returns the `zerolog.Logger` configured for this instance. The log level and
format are set from `Options.LogLevel` and `Options.LogFormat`.

---

### `Version`

```go
func (p *Probot) Version() string
```

Returns the version string of the probot-go port (e.g. `"0.1.0"`). Identical
to reading the package-level `Version` constant.

---

### `WebhookPath`

```go
func (p *Probot) WebhookPath() string
```

Returns the URL path the webhook handler is mounted on (e.g.
`"/api/github/webhooks"`). Derived from `Options.WebhookPath`.

---

### `Options`

```go
func (p *Probot) Options() Options
```

Returns a **copy** of the current `Options`. Thread-safe: the internal
credentials lock is acquired for reading before the copy is made. Use this to
inspect configuration without risking data races.

---

### `AppID`

```go
func (p *Probot) AppID() int64
```

Returns the numeric GitHub App ID, or `0` when the instance was created with a
`GithubToken` or is unconfigured. Thread-safe.

## Event Registration

### `On`

```go
func (p *Probot) On(eventName string, fn HandlerFunc)
```

Subscribes `fn` to a single webhook event. `eventName` may be:

- A **bare event name** — `"issues"` — to match all actions for that event.
- A **qualified name** — `"issues.opened"` — to match only that action.

<ParamField path="eventName" type="string" required>
  Bare event name (e.g. `"push"`) or qualified event name (e.g.
  `"pull_request.opened"`).
</ParamField>

<ParamField path="fn" type="HandlerFunc" required>
  The handler to invoke when a matching event is received.
</ParamField>

```go
app.On("issues.opened", func(ctx *probot.Context) error {
    repo, _ := ctx.Repo()
    ctx.Log().Info().Str("repo", repo.Repo).Msg("issue opened")
    return nil
})
```

---

### `OnMany`

```go
func (p *Probot) OnMany(eventNames []string, fn HandlerFunc)
```

Subscribes `fn` to multiple events in a single call. Internally calls `On` for
each name in the slice — semantics are identical.

<ParamField path="eventNames" type="[]string" required>
  Slice of bare or qualified event names.
</ParamField>

<ParamField path="fn" type="HandlerFunc" required>
  Shared handler invoked for every matched event.
</ParamField>

```go
app.OnMany([]string{"issues.opened", "issues.reopened"}, func(ctx *probot.Context) error {
    issue, _ := ctx.Issue()
    ctx.Log().Info().Int("number", issue.Number).Msg("issue needs triage")
    return nil
})
```

---

### `OnAny`

```go
func (p *Probot) OnAny(fn HandlerFunc)
```

Subscribes `fn` to **every** webhook event regardless of name or action. All
`OnAny` handlers run after the event-specific handlers for every delivery.

<ParamField path="fn" type="HandlerFunc" required>
  Handler invoked for all webhook deliveries.
</ParamField>

```go
app.OnAny(func(ctx *probot.Context) error {
    ctx.Log().Debug().Str("event", ctx.Name()).Msg("received event")
    return nil
})
```

---

### `OnError`

```go
func (p *Probot) OnError(fn ErrorHandlerFunc)
```

Registers an error handler that is called when one or more event handlers
return a non-nil error. The errors from all failed handlers for a single
delivery are joined with `errors.Join` before being passed to `fn`. Only one
error handler can be registered; calling `OnError` a second time replaces the
first.

<ParamField path="fn" type="ErrorHandlerFunc" required>
  Called after all handlers have run. Receives the handler context and the
  joined error.
</ParamField>

```go
app.OnError(func(ctx *probot.Context, err error) {
    ctx.Log().Error().Err(err).Msg("handler error")
})
```

## Application Loading

### `Load`

```go
func (p *Probot) Load(fns ...ApplicationFunc) error
```

Invokes one or more `ApplicationFunc` values with this `Probot` instance and an
`ApplicationFunctionOptions{Cwd: "."}`. Functions run **synchronously** in
order; handlers they register are available immediately after `Load` returns.
Returns the first error returned by any function.

<ParamField path="fns" type="...ApplicationFunc" required>
  One or more plugin functions to execute against this instance.
</ParamField>

```go
func myPlugin(app *probot.Probot, opts probot.ApplicationFunctionOptions) error {
    app.On("push", func(ctx *probot.Context) error {
        ctx.Log().Info().Msg("push received")
        return nil
    })
    return nil
}

if err := app.Load(myPlugin); err != nil {
    log.Fatal(err)
}
```

## Authentication

### `Auth`

```go
func (p *Probot) Auth(installationID ...int64) (*github.Client, error)
```

Returns an authenticated `*github.Client`. With **no arguments** (or
`installationID[0] == 0`) it returns the app-level client authenticated via a
JWT signed with the app's private key. With an installation ID it returns an
installation-scoped client whose access token is automatically refreshed by the
underlying `ghinstallation` transport.

Installation clients are cached per ID; the cached client is returned on
subsequent calls for the same installation.

<ParamField path="installationID" type="...int64">
  Optional installation ID. Omit or pass `0` for the app-level client.
</ParamField>

<Note>
  Inside webhook handlers, prefer `ctx.GitHub()` or `ctx.Octokit()`, which are
  pre-authenticated for the installation that triggered the event without
  requiring you to extract the installation ID manually.
</Note>

```go
// App-level client (for listing installations, etc.)
client, err := app.Auth()

// Installation-scoped client
client, err := app.Auth(12345678)
```

## Event Dispatching

### `Receive`

```go
func (p *Probot) Receive(event WebhookEvent) error
```

Dispatches a `WebhookEvent` through the full handler pipeline: it builds a
`Context`, matches registered `On`/`OnMany` subscriptions against
`event.Name` and the qualified `event.Name + "." + action` form, then runs all
`OnAny` handlers. Errors from individual handlers are joined and forwarded to
the registered `ErrorHandlerFunc`.

Returns the joined error from all failed handlers, or `nil` if all succeeded.

<ParamField path="event" type="WebhookEvent" required>
  The event to dispatch. See [WebhookEvent](/api/webhook#webhookevent-struct).
</ParamField>

```go
// Useful in tests — bypass HTTP entirely.
err := app.Receive(probot.WebhookEvent{
    Name: "issues",
    ID:   "test-delivery-1",
    Payload: map[string]any{
        "action": "opened",
        "issue":  map[string]any{"number": float64(42)},
        "repository": map[string]any{
            "name":  "my-repo",
            "owner": map[string]any{"login": "acme"},
        },
    },
})
```

## GitHub Actions Integration

### `RunAction`

```go
func (p *Probot) RunAction() error
```

Reads `GITHUB_EVENT_PATH` and `GITHUB_EVENT_NAME` from the environment, parses
the event JSON file, and dispatches it to the registered handlers via
`Receive`. The delivery ID is taken from `GITHUB_RUN_ID` when set, otherwise
`"action"` is used.

Returns an error if either environment variable is missing, if the file cannot
be read, or if the JSON cannot be parsed.

<Warning>
  `RunAction` blocks until all handlers for the single event have completed and
  then returns. It does not start an HTTP server. Use it in a `main()` that
  detects the `GITHUB_ACTIONS` environment variable.
</Warning>

```go
func main() {
    app, _ := probot.New(probot.Options{GithubToken: os.Getenv("GITHUB_TOKEN")})
    app.On("issues.opened", handler)

    if os.Getenv("GITHUB_ACTIONS") == "true" {
        log.Fatal(app.RunAction())
    }
    // ... start HTTP server otherwise
}
```

## HTTP Handlers

### `WebhookHandler`

```go
func (p *Probot) WebhookHandler() http.HandlerFunc
```

Returns a `net/http`-compatible handler that:

1. Rejects non-POST requests with `405 Method Not Allowed`.
2. Reads `X-GitHub-Event`, `X-GitHub-Delivery`, and `X-Hub-Signature-256` headers.
3. Verifies the HMAC-SHA256 signature against `Options.Secret`.
4. Parses the JSON body and calls `Receive`.
5. Responds `200 OK` on success, `400` for bad input, or `401` for an invalid signature.

Mount this directly when you control the router.

```go
mux := http.NewServeMux()
mux.Handle("/api/github/webhooks", app.WebhookHandler())
http.ListenAndServe(":3000", mux)
```

---

### `WebhookMiddleware`

```go
func (p *Probot) WebhookMiddleware() func(http.Handler) http.Handler
```

Returns a standard middleware function (compatible with gorilla/mux,
chi, and similar routers). It intercepts requests whose path matches
`Options.WebhookPath` and handles them as webhooks; all other requests are
passed to the wrapped `next` handler.

```go
// With chi
r := chi.NewRouter()
r.Use(app.WebhookMiddleware())
r.Get("/", homePage)
http.ListenAndServe(":3000", r)
```

---

### `Handler`

```go
func (p *Probot) Handler(next ...http.Handler) http.Handler
```

Returns a minimal `http.Handler` suitable for use as a top-level server
handler. Requests to `Options.WebhookPath` are routed to `WebhookHandler`;
all other requests are forwarded to `next[0]` when provided, or answered
with `404 Not Found` when no `next` is given.

<ParamField path="next" type="...http.Handler">
  Optional fallback handler for non-webhook paths. Pass nothing or `nil` to
  serve `404` for all other paths.
</ParamField>

```go
// Standalone — 404 for everything except the webhook path
http.ListenAndServe(":3000", app.Handler())

// With a custom fallback
http.ListenAndServe(":3000", app.Handler(myMux))
```
