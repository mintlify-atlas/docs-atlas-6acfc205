probot-go is a Go port of [Probot](https://probot.github.io/), the popular Node.js framework for building GitHub Apps. It eliminates the boilerplate of HMAC signature verification, JWT and installation token management, and GitHub API client setup — so you can focus on what your app actually does.

## Why probot-go?

Building a GitHub App from scratch requires wiring together HMAC validation, GitHub App JWT auth, per-installation token refresh, and a GitHub API client — before you write a single line of business logic. probot-go handles all of that.

<CardGroup cols={3}>
  <Card title="Webhook Security" icon="shield-check">
    HMAC SHA-256 signature verification is automatic on every incoming request.
  </Card>
  <Card title="Auto-Refreshing Auth" icon="rotate">
    Installation tokens are cached and transparently refreshed before expiry via `ghinstallation`.
  </Card>
  <Card title="Ready-to-Use Client" icon="plug">
    Every handler receives a `*github.Client` already authenticated for the triggering installation.
  </Card>
  <Card title="Setup Wizard" icon="wand-magic-sparkles">
    Register a new GitHub App in one click via the built-in manifest flow — no manual configuration.
  </Card>
  <Card title="Repo Config" icon="file-code">
    Load `.github/config.yml` with defaults and cross-repo `_extends` inheritance.
  </Card>
  <Card title="GitHub Actions" icon="circle-play">
    Run your app as a GitHub Action with a single `RunAction()` call — no server needed.
  </Card>
</CardGroup>

## Get Started

<Steps>
  <Step title="Install the package">
    ```bash
    go get github.com/Pratyay360/probot-go
    ```
  </Step>
  <Step title="Create your app">
    ```go main.go
    package main

    import (
        "context"
        "os"

        "github.com/google/go-github/v88/github"
        probot "github.com/Pratyay360/probot-go"
    )

    func main() {
        app, err := probot.New(probot.Options{
            AppID:      os.Getenv("APP_ID"),
            PrivateKey: os.Getenv("PRIVATE_KEY"),
            Secret:     os.Getenv("WEBHOOK_SECRET"),
        })
        if err != nil {
            panic(err)
        }

        app.On("issues.opened", func(ctx *probot.Context) error {
            issue, _ := ctx.Issue()
            _, _, err := ctx.GitHub().Issues.CreateComment(
                context.Background(), issue.Owner, issue.Repo, issue.Number,
                &github.IssueComment{Body: github.Ptr("Thanks for opening this issue!")},
            )
            return err
        })

        probot.NewServer(probot.ServerOptions{Probot: app}).Start()
    }
    ```
  </Step>
  <Step title="Configure credentials">
    Set environment variables or let the setup wizard create them for you:
    ```bash
    export APP_ID=12345
    export PRIVATE_KEY_PATH=~/my-app.pem
    export WEBHOOK_SECRET=my-secret
    ```
  </Step>
  <Step title="Run and register">
    ```bash
    go run main.go
    ```
    Visit `http://localhost:3000` — if no credentials are set, the setup wizard walks you through registering a new GitHub App in one click.
  </Step>
</Steps>

<Note>
  New to GitHub Apps? The [setup wizard](/guides/server-setup#setup-wizard) at `http://localhost:3000` handles GitHub App registration automatically using the manifest flow — no manual configuration on GitHub.com required.
</Note>
