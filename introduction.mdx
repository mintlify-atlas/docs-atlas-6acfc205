probot-go is a Go port of [Probot](https://probot.github.io/) — the popular Node.js framework for building GitHub Apps. It takes all the tedious plumbing out of the picture: HMAC signature verification, JWT-based App authentication, per-installation token refresh, and HTTP server bootstrapping all happen automatically. You register event handlers and write the business logic; probot-go handles everything else.

## Why probot-go?

Building a GitHub App from scratch in Go means wiring together HMAC validation, JWT minting, installation token exchange, and a GitHub API client before you can write a single line of business logic. probot-go compresses all of that into a single `probot.New()` call.

## Key Features

<CardGroup cols={2}>
  <Card title="HMAC Webhook Validation" icon="shield-check">
    Every incoming payload is verified against your webhook secret using `X-Hub-Signature-256` before any handler runs. Invalid or missing signatures are rejected automatically.
  </Card>
  <Card title="Auto-Refreshing Installation Tokens" icon="arrows-rotate">
    Uses [`ghinstallation`](https://github.com/bradleyfalzon/ghinstallation) to exchange your App's private key for short-lived installation tokens. Tokens are refreshed transparently before they expire.
  </Card>
  <Card title="Pre-Authenticated GitHub Client" icon="plug">
    Each handler receives a `*probot.Context` that exposes a fully authenticated `*github.Client` (from `go-github`) scoped to the triggering installation — no manual auth setup needed.
  </Card>
  <Card title="Event-Driven Handler API" icon="bolt">
    Register handlers with `On`, `OnMany`, `OnAny`, and `OnError`. Event names follow GitHub's `event.action` dot notation (e.g. `issues.opened`).
  </Card>
  <Card title="Setup Wizard" icon="wand-magic-sparkles">
    When no credentials are configured, visiting `http://localhost:3000` opens a one-click GitHub App registration flow using the manifest API. Credentials are written to a `.env` file automatically.
  </Card>
  <Card title="Repo Config Loading" icon="file-code">
    `ctx.Config("config.yml", defaults)` reads `.github/config.yml` from the target repository, applies default values, and resolves `_extends` cross-repository inheritance.
  </Card>
  <Card title="GitHub Actions Support" icon="github">
    Call `app.RunAction()` to read `GITHUB_EVENT_PATH` and `GITHUB_EVENT_NAME` and dispatch the event payload through your handlers — no HTTP server needed.
  </Card>
  <Card title="Webhook Proxy" icon="network-wired">
    Set `WebhookProxyURL` to a [Smee.io](https://smee.io) channel URL and probot-go will automatically connect an SSE client that forwards events to your local server during development.
  </Card>
</CardGroup>

## How It Compares to Writing from Scratch

When you build a GitHub App without a framework, you handle several layers of infrastructure yourself:

| Concern | Without probot-go | With probot-go |
|---|---|---|
| Webhook signature check | Manual HMAC + constant-time compare | Built-in, automatic |
| App-level authentication | JWT generation with RSA key | `probot.New()` sets it up |
| Installation token refresh | Manual REST calls + expiry tracking | `ghinstallation` handles it |
| GitHub API client | Manually construct `go-github` client | Available as `ctx.GitHub()` |
| Event routing | Custom mux on `X-GitHub-Event` + `action` | `On("issues.opened", fn)` |
| Dev tunnel for local testing | External tool only | Built-in Smee proxy client |
| App registration | Manual GitHub UI steps | Setup wizard at `/` |

## Minimal Example

The following snippet is a complete GitHub App. It uses no configuration beyond environment variables and responds to every newly opened issue with a comment.

```go
package main

import (
    "context"
    "os"

    "github.com/google/go-github/v88/github"
    probot "github.com/Pratyay360/probot-go"
)

func main() {
    app, err := probot.New(probot.Options{
        AppID:      os.Getenv("APP_ID"),
        PrivateKey: os.Getenv("PRIVATE_KEY"),
        Secret:     os.Getenv("WEBHOOK_SECRET"),
    })
    if err != nil {
        panic(err)
    }

    app.On("issues.opened", func(ctx *probot.Context) error {
        issue, err := ctx.Issue()
        if err != nil {
            return err
        }
        _, _, err = ctx.GitHub().Issues.CreateComment(
            context.Background(), issue.Owner, issue.Repo, issue.Number,
            &github.IssueComment{Body: github.Ptr("Thanks for opening this issue!")},
        )
        return err
    })

    probot.NewServer(probot.ServerOptions{Probot: app}).Start()
}
```

<Tip>
  If `APP_ID`, `PRIVATE_KEY`, and `WEBHOOK_SECRET` are not set when you start the server, visiting `http://localhost:3000` opens the setup wizard and guides you through registering the app on GitHub.
</Tip>
